## `$ about`

Saptarshi builds software by first taking apart the layer beneath it - how a request moves through a distributed system, why an automation flow breaks under edge cases, what a cloud service is actually doing when it "just works." That instinct shows up across his work: cloud infrastructure, agentic AI systems, and backend architecture, held together by the same habit of tracing a problem to its root before writing the fix.

At KIIT University, he studies Computer Science Engineering while representing MathWorks as a Student Ambassador and contributing to open source. He competes because constraints force clarity - hackathons and challenge platforms are where half-formed ideas get pressure-tested fast.

interests: [cloud computing, agentic ai, backend engineering,
            distributed systems, devops, automation,
            software architecture, open source]
